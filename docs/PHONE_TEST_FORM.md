# แบบฟอร์มทดสอบ SAFE บนมือถือจริง

> พิมพ์ออกมา 1 แผ่นต่อมือถือ 1 เครื่อง แล้วจดผลระหว่างลอง · ใช้เวลาประมาณ 1 ชั่วโมง
> ถ่ายภาพหน้าจอทุกขั้นที่ขึ้นผล (ใช้แทนภาพจาก emulator ในโปสเตอร์และสไลด์ได้) แล้วส่งแบบฟอร์ม + ภาพให้ฝั่งพัฒนา

## ติดตั้ง
1. บนมือถือ เปิด https://github.com/PanuwatKi/SAFE-i-new-gen/releases → รุ่นทดสอบล่าสุด → กดไฟล์ `.apk` (ไม่ต้องล็อกอิน)
2. เปิดไฟล์ → อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" (เฉพาะเครื่องทดสอบ ปิดกลับหลังติดตั้ง)
   - รุ่นที่ใหม่กว่า Release: ล็อกอิน GitHub → แท็บ **Actions** → **Android CI** รอบล่าสุดที่เป็นสีเขียว → **Artifacts** → `safe-debug-apk`
