# ชุดเดโมวันแข่ง (ดับเบิลคลิกได้เลย บน Windows)

ใช้ตอนนำเสนอที่บูธ โดยไม่ต้องพิมพ์คำสั่งเอง และไม่ต้องพึ่ง Wi-Fi ของงาน

| ไฟล์ | ทำอะไร | ใช้เมื่อ |
|------|--------|----------|
| `1_web_offline.bat` | เปิดเว็บแอป SAFE จากเครื่องนี้ ที่ http://localhost:8765 | ให้กรรมการลองตรวจข้อความ / ตอบ 5 ข้อ / ดูเดโมสายเข้า |
| `2_start_emulator.bat` | เปิดมือถือจำลองใน Android Studio (ตัวแรกที่มี) | ก่อนโชว์สายเข้า (รอประมาณ 1 นาที) |
| `3_call_697.bat` | จำลองสายเข้าจากเบอร์ +697 123 456 789 | โชว์ "SAFE เตือนสีแดงตั้งแต่สายดัง" |
| `4_end_call.bat` | วางสายที่จำลองไว้ | หลังโชว์เสร็จ |
| `5_install_apk.bat` | ติดตั้งไฟล์ `.apk` ล่าสุดในโฟลเดอร์นี้ ลงมือถือจำลองหรือมือถือที่เสียบสาย | อัปเดตแอปก่อนวันแข่ง |

## ต้องมีในโน้ตบุ๊ก
- **Python** (สำหรับข้อ 1) — ติดตั้งจาก python.org
- **Android Studio** และมือถือจำลอง 1 เครื่อง (สำหรับข้อ 2–5)
- ไฟล์ `.apk` รุ่นล่าสุด: GitHub → Actions → **Android CI** รอบล่าสุดที่เป็นสีเขียว → Artifacts → `safe-debug-apk` → แตกไฟล์แล้ววาง `.apk` ไว้ในโฟลเดอร์นี้ (ไฟล์ .apk ไม่ขึ้น GitHub)

## ลำดับเดโม 3 นาที (ตรงกับ docs/COMPETITION_GUIDE.md ข้อ 5)
1. ดับเบิลคลิก `2_start_emulator.bat` ไว้ก่อนกรรมการมาถึง
2. เปิดแอป SAFE ในมือถือจำลอง → ชี้ไฟ 3 สีและหน้าตั้งค่าทีละขั้น
3. ดับเบิลคลิก `3_call_697.bat` → SAFE เตือนสีแดง → `4_end_call.bat`
4. ดับเบิลคลิก `1_web_offline.bat` → แท็บ "ดูเดโมสายเข้า" → "แก๊งอ้างเป็นตำรวจ" สีเปลี่ยน 19% → 98% · "ธนาคารโทรมาจริง" เขียวตลอด
5. ให้กรรมการสแกน QR บนโปสเตอร์ ลองวาง SMS ที่เคยได้รับบนมือถือตัวเอง

## ซ้อมก่อนวันแข่ง (สำคัญ)
- [ ] **ปิด Wi-Fi แล้วลองทุกไฟล์** ให้แน่ใจว่าใช้ได้แม้ไม่มีอินเทอร์เน็ต (ตอนออฟไลน์ ตัวอักษรในเว็บจะเป็นฟอนต์ของเครื่องแทน ไม่เป็นไร)
- [ ] ลองสายเข้า +697 แล้ว SAFE ขึ้นเตือนจริง (แอปต้องตั้งค่าครบในมือถือจำลองก่อน)
- [ ] อัดคลิปหน้าจอทุกขั้นเก็บไว้ ถ้าเครื่องมีปัญหาหน้างาน เปิดคลิปแทนได้ทันที
- [ ] ชาร์จโน้ตบุ๊กเต็ม + สายชาร์จ

ถ้าดับเบิลคลิกแล้วขึ้นข้อความภาษาไทยอ่านไม่ออก ไม่เป็นไร สคริปต์ยังทำงานได้ปกติ
